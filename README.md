## 🚀 Featured Projects

### 🎵 [Spotify AI Memory Studio](https://github.com/Mansi12-cmd/spotify-ai) — Real-Time Personalization
An AI-powered music assistant that uses Spotify data and user preferences to deliver personalized recommendations.

- Processed **10,000+ tracks** using Spotify metadata and audio features (tempo, energy, acousticness).
- Converted user memories and preferences into **384-dimensional embeddings** with Sentence Transformers for semantic similarity search.
- Combined **ChromaDB** (vector retrieval) and **Neo4j** (relationships between users, preferences, artists, and music).
- Built **FastAPI** endpoints for query, memory creation, retrieval, update, and deletion, with the **Gemini API** generating personalized responses.

**Tech:** `Python` `FastAPI` `Spotify API` `Neo4j` `ChromaDB` `Sentence Transformers` `Gemini API`

---

### 🏠 [Airbnb Market Analysis Dashboard](https://github.com/Mansi12-cmd/airbnb-market-analysis-dashboard)
An interactive Power BI dashboard analysing Airbnb listings to uncover pricing and host performance trends.

- Analysed **12,464 listings** across Chicago and New Orleans using Python and Pandas.
- Cleaned raw data (duplicates, nulls) and created price categories for analysis-ready datasets.
- Designed a dashboard with **4 KPI cards** (Total Listings, Average Price, Total Hosts, Total Reviews) and **5+ analytical visuals**.

**Tech:** `Python` `Pandas` `Power BI` `DAX`

---

### 🛒 [Flipkart E-commerce Database Analysis](https://github.com/Mansi12-cmd/Flipkart-Product-Dissection)
A relational database design for an e-commerce platform, paired with business problem analysis.

- Modeled **8 core entities** (Customers, Products, Orders, Sellers, Payments, Deliveries, etc.) in an ER diagram.
- Mapped One-to-One, One-to-Many, and Many-to-Many relationships to reflect real business data flow.
- Identified **4 key business challenges** (high returns, cart abandonment, delivery delays) and proposed data-driven strategies to improve retention and revenue.

**Tech:** `SQL` `Excel` `ER Modeling`
